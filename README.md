# סליחה על השאלה — ילדים

אתר סטטי בעברית (HTML, CSS, JS) המתאים ל-GitHub Pages.

- כולל רק עונות 2–4, בסך הכול 30 פרקים.
- עונה 1 הוסרה מקובץ הנתונים ומתפריט העונות, עקב חוסר זמינות לצפייה באתר. אין בכך קביעה רשמית שכאן מחקה את התוכן מכל שירותיה.
- שמות הפרקים, מספרי העונות, תאריכי השידור ותוכן השאלות נבדקו מול: https://thetvdb.com/series/you-cant-ask-that-kids/allseasons/official
- עונה 4: https://israelfilmacademy.co.il/?item=381109&section=2392
- תיאור הפרק הוא ניסוח מקוצר/מורחב בעברית לפי השאלות שהופיעו בתקציר המתועד. אין לייחס למשתתפים תשובות שלא נבדקו בפרק עצמו.
- המלצות הכיתות ורמות הרגישות הן הערכות בלבד ולא דירוג גיל רשמי; יש לצפות מראש בפרק לפני הקרנה בית־ספרית.
- סרטוני YouTube ישנים נשמרו מהאתר הקודם כדי לא לשבור חיבורים קיימים, אך לא אושרה בדיקת ניגון חי או הטמעה של כל סרטון. אם סרטון חסום אפשר לפתוח ב-YouTube, או להזין קישור חלופי מקומי דרך הממשק.

## פריסה

יש להעלות את חמשת הקבצים לשורש מאגר GitHub ולבחור ב-Settings → Pages → Deploy from a branch → main / (root).

## תיקון נגן YouTube והפונט

- האתר מגדיר `strict-origin-when-cross-origin` גם ב־`meta referrer` וגם על ה־iframe.
- הנגן משתמש ב־`www.youtube.com/embed/` במקום ב־`youtube-nocookie.com/embed/`.
- אם פותחים את `index.html` ישירות בתור `file://`, לא נטען iframe (לכתובת מקומית כזו אין Referer אמין); ניתן לעבור לצפייה ביוטיוב. להטמעה יש לפרסם ב־GitHub Pages באמצעות HTTPS.
- במקרים של הרשאות, הגדרות פרטיות, תוספי דפדפן או חסימת הטמעה מצד בעל הסרטון, ניגון פנימי עדיין עלול להיחסם. הקישור הישיר ליוטיוב נשאר זמין.
- הפונט הוא Heebo (600–900) דרך Google Fonts, עם Arial כגיבוי. האתר דורש חיבור לאינטרנט כדי לטעון את הפונט ואת הסרטונים.
